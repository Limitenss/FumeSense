# FumeSense

## Reviewer Message: please view the f3z file instead of the f3d, it contains the fully assembled case.

The FumeSense smart fume extractor is powered by an ESP32-S3. It features an Adafruit BME688 sensor that instantly detects harmful VOCs and activates a high-pressure fan to pull the fumes through an activated carbon filter. It also displays real-time data on a 2.4-inch LCD dashboard.

## Core Features

* **Auto-Detect & Remove:** Uses a gas to monitor the air. The moment VOCs from solder flux are detected, the system automatically ramps up the fan speed.
* **Hands-Free:** Both of your hands stay completely occupied with your soldering iron and components.
* **Filter Optimization:** Running a fan at 100% all the time unnecessarily wastes the active carbon compound by filtering clean room air. The auto-detect & remove feature ensures the carbon is only working when required, maximizing filter life.
* **Dashboard:** Features a Waveshare 2.4-inch LCD Module that displays fan-speed, and air info.
* **Manual Override:** Includes up and down buttons to let you instantly change the fan speed if you want to override the auto fan-speed.
